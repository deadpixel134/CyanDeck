# CyanDeck Phase 1.5 — Windows 수동 스모크 테스트

**범위:** 사용자에게 표시되는 이름만 점검. `DesktopDeck.exe`, `%APPDATA%\DesktopDeck`, `%LOCALAPPDATA%\DesktopDeck`, OAuth 리소스, 자동 업데이트 서명과 AppUserModelID는 그대로 유지한다. GitHub Actions 성공만으로 실제 GUI·Explorer·OAuth 작동을 입증하지 않는다.

## 준비 및 안전

1. Windows 10/11, win-x64에서 별도 테스트 계정 또는 격리된 테스트 PC를 사용한다. ARM64는 가능할 때 추가 확인한다.
2. **기존 사용자 프로필·바탕화면·아이콘·캘린더 원본은 테스트 대상으로 삼지 않는다.** 테스트 계정에서 만든 샘플 파일과 캘린더 일정만 사용한다.
3. 테스트 계정의 `%APPDATA%\DesktopDeck`, `%LOCALAPPDATA%\DesktopDeck`은 파일 복사로 별도 백업한다. 설치 폴더와 기존 `DesktopDeck.exe`도 복사본으로 보관한다.
4. 가능하면 테스트용 Google 계정을 사용한다. Google OAuth 토큰 파일, 로그, 사용자 데이터, 개인 키, 인증 JSON은 GitHub에 올리지 않는다.
5. 실제 사용자 파일을 삭제하거나 복구 동작을 강제로 유발하지 않는다. 위험한 테스트는 새 임시 폴더와 임시 샘플 파일만 사용한다.

## 이상 발생 시

- 정상적인 앱 종료를 우선하고, 기존 프로필/원본을 덮어쓰지 않는다.
- 해당 단계의 Windows 버전, 실행 바이너리 버전, 재현 절차를 기록한다.
- 로그에 개인 정보·토큰·경로가 포함될 수 있으므로 공개 이슈에 첨부하지 않는다.
- 실제 릴리스 배포는 별도의 명시적 승인 후 진행한다.
