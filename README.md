## 업데이트 중 바탕화면 표시 안정화 (v8.0.5 Beta)

- 자동 설치를 켠 상태로 CyanDeck을 시작하면 **바탕화면 그룹과 캘린더를 표시하기 전에** 짧은 업데이트 사전 검사를 수행합니다.
- 새 업데이트가 있으면 시작 화면에 다운로드·서명/해시 검증 단계가 표시됩니다. 다운로드를 건너뛰고 기존 버전을 실행할 수 있습니다.
- 설치 단계는 기존 CyanDeck 프로세스와 별도의 PowerShell updater UI에서 상태를 표시합니다. 원래 아이콘과 레이아웃·캘린더 데이터는 변경하지 않습니다.
- 오프라인·통신 시간초과·검증 실패·사용자 건너뛰기 시 기존 버전으로 정상 시작하며, 이미 나타난 그룹이 자동 설치 때문에 사라지지 않도록 해당 실행에서는 재검사를 억제합니다.
- 비정상 종료 보호 안전 모드, 기존 업데이트 복구 대기, 호환성 읽기 전용 모드, 바탕화면 복구 등 특수 실행에서는 자동 사전 설치를 실행하지 않습니다.
- 프로그램이 이미 실행 중일 때의 수동 **업데이트 확인 및 설치**는 기존 사용자 확인을 유지하며, 설치 프로세스 진행 화면은 동일하게 표시합니다.

# CyanDeck

**바탕화면 아이콘 정리부터 일정 관리까지, 한곳에서.**

CyanDeck은 Windows 바탕화면을 작업 공간처럼 정리할 수 있는 무료 다운로드형 데스크톱 프로그램입니다. 아이콘을 그룹과 탭으로 구분하고, 폴더를 바탕화면에서 직접 살펴보거나, Google Calendar 및 로컬 일정을 캘린더에 표시할 수 있습니다.

**지원 환경:** Windows 10/11 · Intel/AMD(x64), Windows on ARM(ARM64)

[**최신 정식 버전 다운로드**](https://github.com/deadpixel134/CyanDeck/releases/latest) · [**전체 릴리스 보기**](https://github.com/deadpixel134/CyanDeck/releases) · [**오류 신고 및 기능 제안**](https://github.com/deadpixel134/CyanDeck/issues)

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| **아이콘 그룹과 탭** | 프로그램, 바로가기, 파일 등을 용도별 그룹에 정리하고 탭으로 나누기 |
| **Folder Portal** | 원하는 폴더의 내용을 바탕화면에서 바로 확인하고 관리하기 |

| **데스크톱 캘린더** | 일정 보기, 추가, 수정, 삭제, 날짜 이동 |
| **Google Calendar 연동** | 여러 캘린더 표시, 저장 대상 선택, 수동·자동 동기화 |
| **로컬 전용 일정** | Google 계정에 업로드하지 않고 내 PC에만 일정 저장 |

| **앱 업데이트** | 정식/베타 채널 선택 및 앱 내 업데이트 확인·설치 |

## 다운로드와 실행

1. [최신 정식 릴리스](https://github.com/deadpixel134/CyanDeck/releases/latest)를 엽니다.
2. 자신의 PC에 맞는 파일을 받습니다.
   - 대부분의 Intel/AMD PC: `CyanDeck-<버전>-win-x64.zip`
   - Windows on ARM 기기: `CyanDeck-<버전>-win-arm64.zip`
3. ZIP 파일을 **폴더에 완전히 압축 해제**합니다. ZIP 안에서 실행하지 마세요.
4. 압축을 푼 폴더의 `CyanDeck.exe`를 실행합니다.

설치해서 사용하려면 압축을 푼 폴더에서 PowerShell을 열어 `./install.ps1`을 실행하세요. 사용자 계정에 CyanDeck을 설치하고 **시작 메뉴 바로가기**를 만듭니다. 설치 경로는 `%LOCALAPPDATA%\Programs\CyanDeck`입니다. 설치하지 않고 압축 해제한 폴더에서 직접 실행하는 것도 가능합니다.

> **안전 안내:** 배포 파일은 공식 GitHub Releases에서 받으세요. 알 수 없는 출처의 파일이나 Windows 보안 경고를 무조건 허용하지 말고, 배포 출처를 먼저 확인하세요. 설치·업데이트 전 중요한 바탕화면 파일의 별도 백업을 권장합니다.

## 처음 사용하는 분을 위한 빠른 시작

### 1. 새 그룹 만들기

1. CyanDeck을 실행한 뒤 작업 표시줄 오른쪽 **알림 영역(트레이)**의 CyanDeck 아이콘을 마우스 오른쪽 버튼으로 클릭합니다.
2. **`새 그룹`**을 선택합니다.
3. 생성된 그룹을 원하는 위치로 옮기고 크기를 조정합니다.
4. 바탕화면 항목을 그룹에 정리하고 그룹 이름이나 모양은 그룹 메뉴 또는 **설정 → 그룹 및 아이콘**에서 조정합니다.

또는 빈 바탕화면에서 마우스로 사각형을 그려 놓으면 **`여기에 새 그룹 만들기`** 메뉴를 사용할 수 있습니다. 사용할 마우스 버튼은 **설정 → 일반 및 바탕화면 → 페이지·입력 제스처**에서 변경할 수 있습니다.

**추천 구성:** 업무 / 개인 / 자주 쓰는 앱처럼 큰 단위로 그룹을 나누어 시작해 보세요.

### 2. 폴더를 바탕화면에 표시하기 (Folder Portal)

1. 빈 바탕화면에서 그룹 생성 제스처로 사각형을 그립니다.
2. **`여기에 Folder Portal 만들기…`**를 선택합니다.
3. 표시할 폴더를 지정합니다.
4. 생성된 Portal에서 해당 폴더의 파일을 확인하고 필요한 작업을 수행합니다.

> **주의:** 일반 Collection 그룹의 항목 참조를 제거하는 것과 Folder Portal에서 실제 파일을 삭제하는 것은 다릅니다. Folder Portal은 실제 파일 시스템을 다루므로 이동·삭제하기 전 대상 경로를 확인하세요.

### 3. 캘린더에서 일정 만들기

1. 바탕화면에 표시된 캘린더에서 **날짜를 더블클릭**합니다.
2. 일정 제목과 날짜·시간을 입력합니다.
3. 저장 위치를 선택합니다.
   - **`로컬에만 저장 (Google 캘린더에 업로드하지 않음)`**: 내 PC에만 저장
   - **저장할 Google 캘린더**: 해당 계정의 캘린더에 동기화할 일정으로 저장
4. 저장합니다. Google Calendar에 반영할 일정이라면 **`동기화`**를 눌러 반영할 수 있습니다.

기존 일정을 **더블클릭**하면 수정·삭제할 수 있습니다. 이동할 수 있는 일정은 **약 2초간 누른 뒤** 다른 날짜로 옮길 수도 있습니다.

캘린더의 **`오늘`** 버튼으로 오늘 날짜에 돌아가고, **`설정`**에서 주/월 보기, 표시할 주 수, 글자 크기 등을 변경합니다. 오른쪽 아래 크기 조절 손잡이로 창 크기를 변경할 수 있습니다.

### 4. Google Calendar 연결하기 (선택)

Google 계정 없이도 **로컬 전용 일정**을 사용할 수 있습니다. 연동을 원한다면 다음 순서로 진행하세요.

1. 캘린더에서 **`설정`**을 엽니다.
2. **`Google 계정 연결 / 캘린더 불러오기`**를 선택합니다.
3. 브라우저에서 Google 로그인 및 권한 승인을 완료합니다.
4. 불러온 캘린더 목록에서 **화면에 표시할 캘린더**를 선택합니다.
5. 새 일정의 **기본 저장 대상**을 선택하고 캘린더의 **`동기화`** 버튼으로 가져오기·반영을 진행합니다.

읽기 전용 캘린더에는 새 일정을 저장할 수 없습니다. 캘린더 설정의 **자동 동기화 간격**을 변경하거나 `0`으로 지정해 자동 동기화를 끌 수 있습니다. 공식 배포본에는 Google 로그인용 데스크톱 OAuth 설정이 포함되어 있으므로 일반 사용자가 별도 OAuth JSON을 준비할 필요는 없습니다.

### 5. 레이아웃 보존하기

- **트레이 → 레이아웃 스냅샷 → 현재 레이아웃 저장**: 현재 그룹 배치 상태를 기록합니다.
- **트레이 → 레이아웃 스냅샷 → 스냅샷 미리보기 / 관리…**: 저장된 배치를 살펴봅니다.
- **트레이 → 백업 / 복원 → 레이아웃 및 설정 내보내기…**: 배치와 앱 설정을 별도 파일로 보관합니다.

레이아웃 백업은 모든 실제 파일이나 Google 계정 데이터의 백업을 의미하지 않습니다. 중요한 자료와 로컬 일정 데이터는 별도로 백업하세요.

## 업데이트 방법

**트레이 → `설정…` → 정보 및 문제 해결 → 업데이트**로 이동하세요.

| 옵션 | 설명 |
| --- | --- |
| **정식 채널 (기본값)** | 안정판으로 공개된 버전만 확인 |
| **베타 채널 업데이트 활성화** | 정식판과 공개 베타(Prerelease) 중 더 높은 버전 확인 |
| **프로그램 실행 시 GitHub Releases 업데이트 확인** | 실행할 때 새 버전 확인 |
| **검증된 새 버전 자동 설치 후 재시작** | 별도로 활성화하면 업데이트를 자동 설치 |
| **업데이트 확인 및 설치…** | 지금 새 버전을 확인하고 설치 안내 진행 |

모든 자동 업데이트는 서명 및 패키지 무결성 검증을 거칩니다. **베타 버전은 시험판**이므로 안정성이 중요하다면 기본 정식 채널을 유지하세요. 베타에서 정식 채널로 돌아가더라도 기존 베타 버전이 자동으로 이전 버전으로 내려가지는 않습니다.

## 자주 묻는 질문 (FAQ)

<details>
<summary><strong>Q. 프로그램을 설치하지 않고 사용할 수 있나요?</strong></summary>

네. 공식 ZIP을 완전히 압축 해제한 뒤 `CyanDeck.exe`를 실행할 수 있습니다. 시작 메뉴 바로가기를 원하면 포함된 `install.ps1`을 이용하세요.
</details>

<details>
<summary><strong>Q. 원래 Windows 바탕화면 아이콘이 사라진 것 같아요.</strong></summary>

CyanDeck은 기본 설정에 따라 Windows 기본 바탕화면 아이콘을 **화면에서 숨기고** 자체적으로 표시할 수 있습니다. 이는 원본 파일을 삭제하는 동작이 아닙니다. 트레이 메뉴에서 **`Windows 바탕화면 아이콘 표시`** 또는 **`Windows Explorer 기본 아이콘 긴급 복구`**를 확인하세요.
</details>

<details>
<summary><strong>Q. 아이콘 그룹이 갑자기 보이지 않아요.</strong></summary>

다른 바탕화면 페이지로 이동했거나 **빠른 숨김**이 켜졌을 수 있습니다. 트레이에서 **`표시 상태 복구`**를 먼저 선택하세요. 계속 보이지 않으면 **`바탕화면 연결 / 레이아웃 복구`**를 시도하고, 문제가 반복되면 아래 오류 신고 안내에 따라 진단 파일을 남겨 주세요.
</details>

<details>
<summary><strong>Q. Google 계정 없이 일정 관리가 가능한가요?</strong></summary>

가능합니다. 일정 작성 시 **`로컬에만 저장`**을 선택하면 Google에 업로드하지 않습니다. 이 일정은 해당 PC의 CyanDeck 데이터에 저장됩니다.
</details>

<details>
<summary><strong>Q. Google Calendar에 일정이 바로 보이지 않아요.</strong></summary>

캘린더의 **`동기화`**를 눌러 보세요. Google 계정 연결 상태, 저장 대상 캘린더 및 해당 캘린더의 쓰기 권한도 확인하세요. 로컬 전용으로 저장한 일정은 Google에 업로드되지 않습니다.
</details>

<details>
<summary><strong>Q. 여러 Google 캘린더를 한 화면에 볼 수 있나요?</strong></summary>

네. 캘린더 **`설정`**에서 여러 캘린더의 표시 여부를 선택할 수 있습니다. 새 일정을 어느 캘린더에 저장할지도 별도로 지정할 수 있습니다.
</details>

<details>
<summary><strong>Q. 캘린더 크기를 줄이면 일정이 가려지나요?</strong></summary>

v8.0.4부터 날짜 영역에 불필요한 세로 스크롤바가 표시되지 않도록 개선했습니다. 일정이 많을 때는 **마우스 휠·트랙패드·터치 스크롤**을 사용해 다른 내용을 확인할 수 있습니다.
</details>

<details>
<summary><strong>Q. DesktopDeck을 사용 중인데 설정과 아이콘 그룹이 자동으로 옮겨지나요?</strong></summary>

아니요. CyanDeck은 별도의 앱과 데이터 폴더를 사용하며 기존 DesktopDeck 데이터를 **자동으로 가져오거나 삭제하지 않습니다**. 이전 프로그램과 동일한 데이터 공간을 공유하지 않습니다.
</details>

<details>
<summary><strong>Q. 업데이트가 보이지 않거나 실패하면 어떻게 하나요?</strong></summary>

트레이의 **`설정… → 정보 및 문제 해결 → 업데이트`**에서 채널을 확인한 뒤 다시 확인하세요. 설치가 실패하면 CyanDeck을 정상 종료하고, 미완료 업데이트 복구 안내가 있는지도 살펴보세요. 문제가 지속되면 진단 파일과 함께 오류를 신고해 주세요.
</details>

<details>
<summary><strong>Q. 프로그램을 제거하면 일정과 설정도 삭제되나요?</strong></summary>

기본 `uninstall.ps1`은 프로그램 파일을 제거하지만 CyanDeck의 사용자 설정·일정 데이터는 보존합니다. 데이터까지 지우는 별도 옵션이 있으므로 제거 명령을 직접 수정할 때는 주의하세요.
</details>

## 문제 해결 및 오류 신고

문제가 발생하면 다음 순서로 확인해 주세요.

1. 트레이의 **`표시 상태 복구`**, **`설정 검사 / 복구`** 등 상황에 맞는 복구 기능을 확인합니다.
2. **트레이 → `진단 묶음 만들기…`**로 진단 파일을 만듭니다.
3. [GitHub Issues](https://github.com/deadpixel134/CyanDeck/issues)에 **CyanDeck 버전, Windows 버전, 발생한 상황과 재현 방법**을 적어 신고합니다.

**개인정보 주의:** 진단 ZIP, 설정 백업 및 로그에는 파일 경로·사용자 환경 정보가 들어갈 수 있습니다. 공개 이슈에 첨부하기 전에 내용을 확인하고 민감한 정보는 제거하세요. Google 인증 토큰이나 개인 키는 올리지 마세요.

| --- | --- |
| 앱 설치 폴더 | `%LOCALAPPDATA%\Programs\CyanDeck` |
| 그룹·설정 및 로컬 일정 | `%APPDATA%\CyanDeck` |
| 앱 업데이트 캐시 등 | `%LOCALAPPDATA%\CyanDeck` |

설치된 CyanDeck을 제거하려면 **앱을 트레이에서 정상 종료한 후** 설치 폴더의 `uninstall.ps1`을 PowerShell에서 실행하세요. 기본 제거는 사용자 데이터를 지우지 않습니다.

## 업데이트 서명 공개키 누락 복구

v8.0.6 이전 설치에서 키가 없다면 공식 릴리스 ZIP의 `CyanDeck.update-public-key.pem`을 `CyanDeck.exe` 옆에 배치하세요. 기본 설치 경로는 `%LOCALAPPDATA%\Programs\CyanDeck`입니다. 설정에서 별도로 입력한 공개키 경로가 잘못되었다면 비우세요. 임의의 공개키 생성이나 서명 검증 비활성화는 금지합니다. v8.0.7 이후 공식 빌드는 동일한 검증 공개키를 EXE에 내장하면서 ZIP 내의 PEM도 유지합니다.

## 단일 EXE 배포 / EXE-only distribution (v8.0.8+)

Windows x64: 공식 베타 릴리스의 `CyanDeck.exe` 파일 하나만 배포하면 됩니다. Windows ARM64: `CyanDeck-ARM64.exe`를 받은 후 `CyanDeck.exe`로 이름을 바꾸어 배포하세요. 공식 EXE에는 서명 검증용 RSA 공개키와 안전한 설치/롤백용 PowerShell 스크립트가 내장됩니다. 외부 PEM/PS1을 직접 배포할 필요가 없습니다. 업데이트할 때만 `%LOCALAPPDATA%\\CyanDeck\\updates` 아래에 스크립트 및 검증된 ZIP 패키지가 자동으로 만들어집니다.

v8.0.4에서 EXE만 배포한 사용자는 기존 앱에 공개키가 없어 자동 업데이트를 실행할 수 없습니다. 해당 사용자는 작업 표시줄 트레이에서 CyanDeck을 정상 종료하고 공식 v8.0.8 이상 `CyanDeck.exe`로 기존 EXE를 한 번 수동 교체해야 합니다. 이후 베타 채널에서 서명 검증된 자동 업데이트가 가능합니다. 아이콘/레이아웃/로컬 일정 등 사용자 데이터 폴더를 삭제하거나 이동하지 마세요.

## v8.0.9 베타 — 캘린더 날짜별 일정 줄 배치

주간 캘린더에서 종일 일정은 여러 날짜에 걸쳐 같은 수평 줄을 유지하지만, 해당 날짜와 겹치지 않는 시간 지정 일정은 다른 날짜의 종일 일정 때문에 아래로 밀리지 않습니다. 3일·2일 연속 종일 일정이 겹친 날짜는 서로 다른 줄을 차지하며, 시간 지정 일정은 해당 날짜에서 실제 점유된 가장 아래 종일 줄 다음에 표시합니다. 다음 날짜에는 영향을 주지 않습니다. 데이터 또는 동기화 형식은 변경하지 않았습니다.

## 정식 릴리스 운영 — v8.0.10 Stable

정식 릴리스는 `.github/stable-release-request.txt`의 3자리 버전을 `src/CyanDeck/CyanDeck.csproj`의 Version과 일치시켜 `main`에 커밋한 경우에만 별도의 서명 검증 Stable 릴리스 워크플로가 자동 게시합니다. 베타 워크플로는 정식 요청 버전을 건너뜁니다. 정식 출시에는 공용 `CyanDeck.exe`와 ARM64 EXE, 서명된 업데이트 ZIP 및 매니페스트, 전체 소스 ZIP과 SHA256SUMS를 포함합니다. 이번 요청 버전은 v8.0.10 Stable이며, 기존 v8.0.9 베타보다 높기 때문에 정상 동작하는 베타 자동 업데이트 사용자는 정식 버전으로 전환됩니다. 기존 v8.0.4 EXE만 사용하는 경우 신뢰 공개키 부재로 첫 1회 직접 EXE 교체가 필요합니다. 이 앱의 RSA-PSS 업데이트 매니페스트 서명은 Windows Authenticode 서명과 다르며, SmartScreen 경고가 남을 수 있습니다.

## v8.0.11 Beta — 모니터 해제 시 Explorer 기본 아이콘 재노출 방지

모니터 연결 해제/재연결 시 Windows Explorer가 FolderView를 다시 만들며 숨겨 둔 기본 바탕화면 아이콘을 노출할 수 있습니다. 모니터 구성이 안정된 직후와 이어지는 2초 간격의 제한된 3회 검사에서 **아이콘을 숨기도록 설정되어 있는데 실제로 보이는 경우에만** 숨김을 다시 적용합니다. 사용자가 긴급 아이콘 복구를 실행했거나, 기본 아이콘을 표시하도록 설정했거나, 안전 모드/화면 변경 중일 때는 숨기지 않습니다. 그룹의 좌표, 파일, 아이콘 레이아웃, Google 및 로컬 일정은 수정하지 않습니다. 업데이트로 인한 정상 앱 종료/재시작 중 Explorer 기본 아이콘이 잠깐 다시 표시되는 것은 기존 안전 복구 동작입니다.

## v8.0.12 Beta — 모니터 연결 해제 시 그룹 자동 재배치

듀얼 모니터의 한 대를 연결 해제하면 모니터 토폴로지가 안정된 뒤 기존 단일 모니터 레이아웃을 우선 복원합니다. 저장된 레이아웃이 없으면 기존 모니터에 있던 그룹은 유지하고 연결이 끊긴 모니터에 있던 그룹만 빈 공간으로 옮깁니다. 데스크톱 페이지별 겹침을 계산하되 모든 페이지에서 보이는 그룹은 공통 점유 공간으로 취급합니다. 남은 화면이 너무 작으면 겹침을 최소화하고 로그에 기록합니다. 화면 연결을 복구하면 저장된 듀얼 모니터 프로필을 다시 사용합니다. 실제 위치 변경 전에 레이아웃 복구 체크포인트를 저장하며 파일·일정 내용은 수정하지 않습니다. 콜드 부팅 상태에서도 마지막 저장 다중 모니터 프로필로 복원 동작을 시도합니다. '레이아웃 자동 조정: 없음' 설정은 그대로 존중합니다.

## v8.0.31 Beta — 환경설정 정보 구조와 여백 개선

기존 **일반 및 바탕화면** 한 화면에 집중된 설정을 좌측 트리의 6개 전용 메뉴로 분리했습니다. **일반 설정**(모듈, 시작, 바탕화면 분류), **동작 및 입력**(터치·마우스·페이지 제스처, 탭, 그룹 접기, Peek, 빠른 숨김), **모양 및 외관**(파일 미리보기·바로가기 배지·그룹 제목줄·스크롤바·카멜레온·단독 아이콘 투명도), **애니메이션**(페이지/아이콘 전환 효과, 이징, 지속시간, 바운스), **성능 및 최적화**(저장 지연, 대량 작업, 캐시, 비동기 로딩), **배치 및 백업**(모니터 배치, 스냅샷, 일반 설정 초기화, 내보내기/가져오기)입니다.

각 화면에 짧은 설명, 구분된 어두운 카드, 추가 패딩·여백, 더 큰 제목을 적용하고 설정 창 기본 크기를 1040×760으로 늘렸습니다(최소 900×560). 캘린더, Windows 기본 아이콘, 개별 그룹 편집, 정보/문제 해결 메뉴는 그대로 이용할 수 있습니다. 그룹 별 색상·글꼴·아이콘 크기는 **그룹 개별 편집** 메뉴에 남기고 공통 외관 기능만 모양 및 외관으로 이동했습니다. 좌측 검색은 새 카테고리와 항목으로 연결되며 관리 정책 제한과 **적용/확인/취소**의 저장 방식은 유지됩니다. 데이터 마이그레이션 없이 기존 설정값·레이아웃·원본 파일을 보호합니다.


## v8.0.32 Beta — 그룹 개별 편집 메뉴를 모양 및 외관 하위로 이동

환경설정 왼쪽 메뉴의 별도 최상위 **그룹 개별 편집** 항목을 삭제하고, **모양 및 외관 → 그룹 개별 편집** 하위 메뉴로 이동했습니다. 그룹별 배경색·글꼴·아이콘 배치·잠금 및 접기 동작을 다루는 기존 편집기는 별도 하위 화면으로 유지하므로 공통 외관 설정 한 페이지에 복잡한 그룹 편집기를 몰아넣지 않습니다. 그룹 선택 상태, 설정 검색, 적용/확인/취소, 관리 정책의 그룹 편집 권한은 유지합니다. 두 열로 표시되는 그룹 편집기가 좁은 창에서 잘리지 않도록 설정 창 최소 너비를 940으로 조정하고 전용 화면에 설명과 카드 여백을 추가했습니다. 그룹 배치·Google 일정·OAuth·실제 바탕화면 파일 및 저장 포맷은 변경하지 않습니다.
